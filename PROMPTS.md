# Ошибки ИИ

## 1. Прямые запросы к API из браузера

Что попросила: слой API с кешем и очередью.
Что ответил ИИ: код `fetch` напрямую на api.artic.edu, как написано в методичке (CORS разрешён).
Что пошло не так: браузер блокировал запрос с localhost (ошибка CORS), сначала приложение показывало общее «Не удалось загрузить данные», а потом сервер отвечал 403.
Как нашла: открыла Console и вкладку Network, увидела настоящую ошибку, а не сообщение из catch.
Как исправили: прокси Vite `/aic` с очисткой заголовков origin и referer и заголовком AIC-User-Agent.

## 2. Прокси картинок перекрывался прокси API

Что ответил ИИ: два прокси в vite.config.js с ключами `/aic` и `/aicimg`.
Что пошло не так: Vite сопоставляет прокси по началу пути, `/aicimg/...` начинается с `/aic`, поэтому запросы картинок уходили на api.artic.edu и возвращали 404.
Как нашла: во вкладке Network у картинок был статус 404 при правильном Request URL.
Как исправили: ключ `^/aic/` со слэшем, чтобы прокси API не трогал `/aicimg`.

## 3. Команда для другой операционной системы

Что ответил ИИ: `rm -rf node_modules package-lock.json` для очистки проекта.
Что пошло не так: у меня Windows PowerShell, там такого синтаксиса нет, команда упала с ошибкой параметра.
Как нашла: текст ошибки в терминале.
Как исправили: `Remove-Item -Recurse -Force node_modules`.
